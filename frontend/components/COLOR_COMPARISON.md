## 새로 추가된 기능 ✨

### 1. 네온 글로우 효과
```css
/* 브랜드 글로우 */
shadow-glow: 0px 0px 20px rgba(0, 212, 255, 0.3)

/* 수익 글로우 */
shadow-glow-green: 0px 0px 20px rgba(0, 255, 136, 0.3)

/* 손실 글로우 */
shadow-glow-red: 0px 0px 20px rgba(255, 77, 109, 0.3)
```

**사용처**: 버튼 호버, 중요 카드, 수익률 표시

### 2. 유리 효과 (Glassmorphism)
```css
.glass {
  background: rgba(26, 26, 26, 0.7);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.1);
}
```

**사용처**: 모달, 오버레이, 특별한 카드

### 3. 그라데이션
```css
bg-gradient-brand: linear-gradient(135deg, #00d4ff 0%, #0098ff 100%)
bg-gradient-success: linear-gradient(135deg, #00ff88 0%, #00cc6a 100%)
bg-gradient-danger: linear-gradient(135deg, #ff4d6d 0%, #ff1744 100%)
```

**사용처**: 히어로 섹션, 중요한 CTA 버튼

### 4. 네온 테두리
```css
.border-neon { border: 1px solid rgba(0, 212, 255, 0.5); }
.border-neon-green { border: 1px solid rgba(0, 255, 136, 0.5); }
.border-neon-red { border: 1px solid rgba(255, 77, 109, 0.5); }
```

**사용처**: 포트폴리오 카드 (수익/손실 상태 표시)

### 5. 펄스 애니메이션
```css
.pulse-glow {
  animation: pulse-glow 2s ease-in-out infinite;
}
```

**사용처**: 중요한 알림, 실시간 업데이트 표시

## 컴포넌트별 변경 사항

### Button
**Before**: 흰 배경 + 보라색 버튼
```tsx
<Button className="bg-[#7070ff] text-white">클릭</Button>
```

**After**: 검은 배경 + 네온 청록색 버튼 + 글로우
```tsx
<Button className="bg-brand-primary text-brand-text hover:shadow-glow">클릭</Button>
```

### Card (포트폴리오)
**Before**: 흰 카드 + 초록/빨강 텍스트
```tsx
<Card className="bg-white">
  <p className="text-[#4cb782]">+12.5%</p>
</Card>
```

**After**: 어두운 카드 + 밝은 네온 색상 + 글로우 + 네온 테두리
```tsx
<Card className="bg-background-quaternary border-neon-green">
  <p className="text-accent-green glow-green">+12.5%</p>
</Card>
```

### Modal
**Before**: 흰 배경 모달
```tsx
<Modal className="bg-white">
```

**After**: 유리 효과 모달 + 강한 그림자
```tsx
<Modal className="glass shadow-high">
```

### Badge (Mock 데이터)
**Before**: 남색 뱃지
```tsx
<Badge variant="mock" className="bg-[#5e6ad2]/10 text-[#5e6ad2]">
  Mock
</Badge>
```

**After**: 밝은 보라색 뱃지 + 반투명 배경
```tsx
<Badge variant="mock" className="bg-accent-purple/10 text-accent-purple">
  Mock
</Badge>
```
